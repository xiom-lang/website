XIOM project -- offline benchmark

Benchmark of Chaos

A language-safety benchmark platform: it compares programming languages on their ability to produce safe, correct systems code, using the same LLM as the code writer. Not an LLM benchmark -- a language benchmark.

The benchmark runs from a local checkout. The first baseline results are published below, with the report, proof bundle and raw session. Nothing is claimed beyond what those files show.

How it runs

Language matrix

Systems, contracts, scripting and LLM arenas under one harness.

Same LLM for all

The same LLM writes the code for every language -- a language benchmark, not an LLM benchmark.

Arenas

C, C++, Rust, Zig, Go, Ada and XIOM; the contracts arena adds Prusti and SPARK.

Offline run

One Docker Compose command builds the toolchains and installs the pinned, SHA256-verified XIOM release; the dashboard opens on localhost.

Dashboard

Version and digest are surfaced next to every session, or the UI says "not recorded" -- it never guesses.

Digest bindings

Every result is bound to the image digest and a methodology contract version.

Methodology contract

Sessions record the exact runtime and compiler version of every language; reports warn when a selection would mix versions.

Fairness

The fairness and methodology documents are maintained with the benchmark; disputed results are addressed there, not in marketing.

Reproducibility

Arena profiles need no API keys; LLM profiles use keys you provide, and a run is rebuilt from the checkout.
