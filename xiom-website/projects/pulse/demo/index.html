Live demo

This page calls the Pulse service running behind this subdomain -- same origin, no keys -- and prints the raw response, so you can see what the framework actually does. It is a shared, beta service: notes appended below are visible to other visitors, and any limit hit is shown honestly.

Endpoints

GET /health

The check the proxy and uptime monitors use.

GET /api/version

What the live badge reads -- version, commit and build date.

POST /api/echo

Send a message; the service echoes it back as JSON.

POST /api/events | GET /api/events

Append a note to the crash-safe store, then list or count. Other visitors see the same board.

Metrics are Prometheus text but stay restricted at the proxy. Requests are rate limited by the service; if a call is limited, its status shows up in the console above.
