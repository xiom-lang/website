XVector

A vector database engine for the XIOM ecosystem: dense vectors with cosine, dot-product and euclidean metrics, exact flat search, an in-memory HNSW graph, payload filtering and WAL-backed durability -- built on the shared core primitives rather than around them.

Status: the repository is private during development, so there are no public downloads or releases yet. The engine is at release candidate internally; the exact search, the ANN index and the durability path are exercised by suites and probes in the private repository.

What works today

Verified on Windows and Linux. The capability set below is at release candidate, not general availability; the suites and probes live in the repository.

Dense vectors

Dense vector type and math.

Distance metrics

Cosine, dot-product and euclidean.

Exact search

Flat KNN and range search -- the oracle every index is measured against.

Top-K and ranges

Bounded top-K heap; range queries, pagination, batch and delete-by-filter.

HNSW ANN search

Hierarchical layers with greedy descent and bounded edges.

Typed filters

Typed filters, a payload index, pre-filtered search and payload hydration.

WAL durability

WAL durability and recovery for vectors and metadata.

Collections and segments

Multi-collection registry; sealed segments with roll and union reads; snapshots.

Recall harness

Measuring ANN recall against the exact oracle -- in progress.

Multimodal vectors

Image, text, audio, 3D and video embeddings -- on the roadmap.

Also in the release-candidate surface: opt-in SQ8 quantization, an in-process HTTP service surface, a served daemon with API scopes, limits and metrics, and thread support.

What is next

  • Product architecture: the embedded engine is the mote tier; the scale-out lattice tier -- a stateless collection router with online move/drain, replicas next -- is in active development on the same engine.
  • Phase 2: GitHub releases and mirror installers, once the repository opens and the gates pass.

Tier map: mote is the embedded engine registry tier; lattice is the scale-out server tier with standalone releases. Release candidate internally, not GA: there is no public release yet, and nothing here claims production readiness.
