XVector

A vector database engine for the XIOM ecosystem: dense vectors with cosine, dot-product and euclidean metrics, exact flat search, an in-memory HNSW graph, payload filtering and WAL-backed durability -- built on the shared core primitives rather than around them.

XVector is at release-candidate stage (v1.0.0-rc.1). The code is public on GitHub; the embedded engine is available as the xiom.vectors package. There is no public download yet.

Package: xiom.vectors -- the embedded engine, codename mote (live on the registry, incubating; in-process only, no socket or daemon).
Standalone: lattice -- the scale-out server tier with standalone releases (in development).

What works today

Built with XIOM v0.65.5. The embedded engine ships as the xiom.vectors package on the registry.

Dense vectors

Dense vector type and math.

Distance metrics

Cosine, dot-product and euclidean.

Exact search

Flat KNN and range search -- the oracle every index is measured against.

Top-K and ranges

Bounded top-K heap; range queries, pagination, batch and delete-by-filter.

HNSW ANN search

Hierarchical layers with greedy descent and bounded edges.

Typed filters

Typed filters, a payload index, pre-filtered search and payload hydration.

WAL durability

WAL durability and recovery for vectors and metadata.

Collections and segments

Multi-collection registry; sealed segments with roll and union reads; snapshots.

Recall harness

Measuring ANN recall against the exact oracle -- in progress.

Multimodal vectors

Image, text, audio, 3D and video embeddings -- on the roadmap.

Also included: opt-in SQ8 quantization, an in-process HTTP API, a served daemon with auth scopes and rate limiting, metrics with an ordered log ring, a read-only admin UI, and thread support.

Roadmap

XVector is at v1.0.0-rc.1. The roadmap to the production-grade Tier-X gate is ordered, not scheduled; Tier-X is a proof gate, not a date.
