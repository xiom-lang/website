  • Self-hosted compiler emits real LLVM IR for 19/21 example programs
  • Full derive codegen — Eq, Clone, Hash, Ord, Display with GEP, fcmp, zext
  • Contract support with @llvm.trap and invariant_check
  • Match dispatch with icmp chains
  • C runtime: 50+ functions for file I/O, string interning, IR emission
  • NSIS + batch installer for Windows
  • VS Code extension with syntax highlighting

One-Line Install

Windows (PowerShell):

irm https://xiom-lang.org/install.ps1 | iex

macOS / Linux:

curl -fsSL https://xiom-lang.org/install.sh | sh

This downloads the latest version and adds xiom to your PATH.

Build from Source

Requires Rust 1.85+ and LLVM/Clang 18+.

git clone https://github.com/XIOM-lang/XIOM.git 
cd xiom
cargo build --release
cargo test          # 213 tests should pass

The Rust compiler is the bootstrap. The XIOM self-hosted compiler lives in selfhost/. Both are built from the same repository.

Version Manager (Planned)

xiomup will manage multiple XIOM versions — similar to rustup or nvm. Planned for Phase 3. For now, use pre-built binaries or build from source.
