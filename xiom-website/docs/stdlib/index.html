Standard Library

40 modules. All ship with the compiler in stdlib/xiom/.

Types (Option, Result, Vec, Int, Str...) are built-in -- no import needed.

Functions live in modules -- import with use xiom..

Foundation

Module Description
core Option, Result, Box, BinaryHeap, interfaces (Clone, Eq, Ord, Display, Hash, Add, Sub, Mul, Div, Iterator, Default, Drop), conversions, contract methods, numeric limits
error Error interface, From/Into error conversion, IOError, NetError, ParseError
char Unicode character operations: is_digit, is_alpha, is_whitespace, to_upper, to_lower

I/O & Filesystem

Module Description
io Console I/O (print, println, read_line), file operations (read, write, append, copy, remove), directories (create, list), process (exit, args, env_var), timing (time_now, sleep)
path File path manipulation: join, basename, dirname, extension, is_absolute, normalize, home_dir, current_dir, temp_dir

Data Structures

Module Description
collections Vec, Map, Set, VecDeque, BTreeMap, BTreeSet, LinkedList, Queue, Stack
array Fixed-size array operations: len, get, set, fill, slice

Text & Encoding

Module Description
string UTF-8 string operations: length, concat, slice, contains, split, trim, upper/lower, format, replace, index_of, char_at, parse int/float
encoding Text encoding: UTF-8 encode/decode, Base64, Hex

Mathematics

Module Description
math Constants (PI, E, TAU), basic math (sqrt, pow, abs, min, max, floor, ceil, round), trigonometry (sin, cos, tan, asin, acos, atan), exponential/log (exp, log, log2, log10), interpolation (clamp, lerp), random numbers
num Numeric traits: abs, signum, is_positive, is_negative, pow, sqrt, cbrt, gcd, lcm, byte conversion, saturating/wrapping operations
cmp Comparison traits: Compare, PartialOrd, Ord, Eq, min, max, clamp
simd Hardware-accelerated SIMD vectors: Vec4f/Vec8f/Vec16f (Float32), Vec2d/Vec4d/Vec8d (Float64), Vec4i/Vec8i (Int32), Vec8s (Int16), Vec16b (Int8). SSE/AVX/AVX2/AVX-512/NEON with scalar fallback

Concurrency

Module Description
async Async runtime: spawn, Channel (bounded/unbounded, send, recv, try_recv, close)
thread OS thread management: spawn, join, Thread handle, sleep, current, available_parallelism
sync Synchronization primitives: Mutex with MutexGuard, RwLock with ReadGuard/WriteGuard, Condvar, Once, Arc, AtomicBool, AtomicInt, Barrier, Semaphore

Networking

Module Description
net TCP (connect, listen, read/write, close), UDP (bind, send_to, recv_from), HTTP (GET, POST with HttpResponse), NetError

Memory & Pointers

Module Description
mem Memory management: size_of, align_of, swap, replace, zeroed, copy, drop
ptr Pointer utilities: null, is_null, read, write, pointer arithmetic (add, sub, offset)
alloc Memory allocation: alloc, alloc_zeroed, realloc, free
rc Reference counting: Rc (single-threaded), Arc (atomic)

System & Environment

Module Description
os Operating system interface: platform, arch, cpu_count, total_memory, process_id, spawn, set_env
env Environment variables: var, set_var, remove_var, vars, home_dir, temp_dir, current_dir
time Time types: Duration, Instant, SystemTime, DateTime, sleep, now

Utilities

Module Description
iter Iterator combinators: Range, RangeInclusive, map, filter, enumerate, take, skip, chain, zip, collect, fold, count, sum, product, max, min, find, all, any, nth
convert Type conversion traits: From, Into, TryFrom, TryInto, AsRef, AsMut
cell Interior mutability: Cell (copy-based), RefCell (borrow-based)
fmt String formatting: Display trait, format, format_args
hash Hashing infrastructure: Hash trait, Hasher, hash function

Security

Module Description
crypto Cryptography: SHA-256/512, MD5, BLAKE3, HMAC, AES encryption/decryption (GCM), RSA keypair/sign/verify, PBKDF2, Argon2, secure random bytes, constant-time comparison
compress Compression: gzip/gunzip, zlib/unzlib, deflate/inflate
rand Random number generation: Rng type, random, random_range, shuffle, choose
regex Regular expressions: compile, match, find, find_all, replace, split

Tooling

Module Description
test Contract-aware test framework: assert, assert_eq, assert_ne, assert_ok, assert_err, assert_some, assert_none, assert_contract, TestResult, run, run_all, run_filtered
bench Benchmarking: bench, run_benches, black_box
log Structured logging: debug, info, warn, error, set_level
contracts Contract helpers: verify_requires, verify_ensures, verify_invariant
serialize Serialization: Serialize/Deserialize interfaces (JSON, bytes) with contract-preserving invariant checks on deserialization, SerializeError with format detection
reflect Comptime type introspection: type_name, type_size, field_names, variant_names

Interop

Module Description
ffi Zero-cost C FFI: extern "C" blocks, *T raw pointers, unsafe blocks, CStr, CString, libc bindings (malloc, free, strlen, printf, sqrt, pow)
