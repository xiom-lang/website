Roadmap

Build Roadmap

How XIOM is being built. Status reflects what has shipped, not what is planned.

Phases

PhaseFocusStatus
Phase 0Working pipeline: lexer, parser, type checker, LLVM IR, native and WASM targetsshipped
Phase 1Full language surface: ownership, generics, contracts, derive, standard libraryshipped
Phase 2Production hardening: contracts, diagnostics, reliability, standard library coveragein progress
Phase 3Ecosystem and static contracts: package registry, formatter, editor tooling, static proofplanned

Self-hosting

Self-hosting gates are cleared, but no self-hosted release has shipped yet; the bootstrap compiler remains the released toolchain.

Testing

Every release runs the compiler, standard library, and end-to-end suites before publication. Counts change with each release.

Scope

XIOM is a systems language for production use -- not a research language, not a domain-specific language, and not a scripting replacement. See Why for the full purpose, and the release history for what has shipped.
