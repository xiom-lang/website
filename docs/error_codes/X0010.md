# X0010 — Type Mismatch

The compiler expected one type but found another.

## Bad Example
```xiom
fn add(a: Int, b: Int) -> Int {
  return "hello";  // expected Int, found Str
}
```

## Fix
Match the return type to the function's declared return type:
```xiom
fn add(a: Int, b: Int) -> Int {
  return a + b;
}
```

## Notes
- Integer literals (`42`) default to `Int` and coerce to any numeric type (UInt8, Float64, etc.)
- Use `x as Type` for explicit casts between numeric types.
