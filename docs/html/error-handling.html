Error Handling

Error Handling

AXIOM has no exceptions. Functions that can fail return Result[T, E]. Absence of a value is expressed through Option[T]. The compiler enforces exhaustive handling of both at every use site.

Result Type


"kw">fn parse_int(s: "ty">Str) -> "ty">Result["ty">Int, "ty">ParseError] {
  "cm">// ...
}

E in Result[T, E] is any type. No Error interface is required. The standard library provides a StdError interface for its own functions. Library authors are free to use any error type.


"cm">// All valid
"ty">Result["ty">Int, "ty">Str]
"ty">Result[Config, "ty">IOError]
"ty">Result[Data, MyCustomErrorEnum]

The ? Operator

The ? operator returns the error from the current function if the Result is Err. It is syntactic sugar for an explicit match that returns the error.


"kw">fn load_config(path: "ty">Str) -> "ty">Result[Config, "ty">AppError] {
  "kw">let file   = io.read_file(path)?     "cm">// returns "kw">Err on failure
  "kw">let config = parse_config(file)?     "cm">// returns "kw">Err on failure
  "kw">return "kw">Ok(config)
}

? can only appear inside a function that returns Result.

Match Exhaustion

Every match expression must cover all cases. The compiler rejects non-exhaustive matches.


"kw">match parse_int("42") {
  "kw">Ok(n)  => io.print(n.to_str()),
  "kw">Err(e) => io.print_err(e.message),
}

"cm">// Matching an "kw">enum — all variants required
"kw">match state {
  AgentState.Idle              => wait(),
  AgentState.Patrolling(route) => follow(route),
  AgentState.Attacking(target) => engage(target),
  AgentState.Dead(cause)       => log(cause),
}

Use _ as a wildcard to cover remaining cases:


"kw">match value {
  "kw">Some(v) => process(v),
  _       => {}  "cm">// handle all other cases
}

Option Type


"kw">let val: "ty">Option["ty">Int] = "kw">Some(10)

"cm">// Unwrap with default
"kw">let n = val.unwrap_or(0)

"cm">// Pattern "kw">match
"kw">match val {
  "kw">Some(n) => "kw">use(n),
  "kw">None    => handle_absent(),
}

"cm">// Propagate "kw">None with ? (inside a function returning "ty">Option)
"kw">let n = val?

Constructors


"cm">// "ty">Option
"kw">let present = "kw">Some(42)
"kw">let absent: "ty">Option["ty">Int] = "kw">None

"cm">// "ty">Result
"kw">let success = "kw">Ok("done")
"kw">let failure: "ty">Result["ty">Str, "ty">IOError] = "kw">Err("ty">IOError.new("file not found"))

? Propagation Rules

  • Result functions can use ? on both Result and Option values
  • Option functions can use ? on Option values
  • The ? operator requires From for automatic error conversion at propagation sites
  • ? cannot appear outside a function that returns Result or Option

Error Messages

When an unhandled error path exists, the compiler provides a clear error:


error[E0401]: non-exhaustive "kw">match
  --> src/main.ax:12:3
   |
12 |   "kw">match "kw">result {
   |         ^^^^^^ missing arm: "kw">Err(_)
   |
   = help: add a wildcard arm or handle the "kw">Err case explicitly
